Getting started

Kratos OS is currently in active development. The first stable installation image will be published here as soon as it is ready for testing.

  1. Download the latest x86_64 ISO from the downloads page.
  2. Write the image to a USB drive using a trusted imaging tool.
  3. Boot your computer from the USB drive and follow the installer.
02

System requirements

64-bit processor x86_64 Memory 4 GB minimum Storage 20 GB available Boot mode UEFI recommended
